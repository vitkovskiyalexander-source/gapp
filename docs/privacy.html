My rclone Privacy Policy

Last updated: 2 October 2026.

My rclone is a personal file transfer and photo backup configuration operated by Alexander Vitkovskiy. It runs rclone on the owner's devices to copy photo archives into the owner's Google Drive.

Data accessed and collected

The Google Drive API is used to access file and folder names, identifiers, paths, sizes, timestamps and other metadata needed to compare and transfer files. The backup uploads photo and video contents from the owner's iCloud libraries. OAuth access and refresh tokens are stored locally to authorize scheduled jobs. Transfer logs can contain file names, paths, timestamps, transfer statistics and errors. The authorized full Drive scope technically allows reading, editing and deleting Drive files; the configured backup jobs list and copy files.

Purpose and use

Data is used to create personal backups, avoid unnecessary repeat uploads and troubleshoot transfer failures. Google user data is not used for advertising, profiling, sale, or training AI or machine learning models. The application does not generate images.

Sharing and transfers

Files are transferred between the owner's devices, Apple iCloud and the owner's Google Drive as instructed by the owner. Google and Apple process data under their own policies. There is no separate application-operated cloud database and no intentional disclosure to other recipients except as required by applicable law or explicitly directed by the owner.

Security

API transfers use HTTPS. OAuth tokens are stored in a local rclone configuration with restricted file permissions. Logs and local backups are stored on owner-controlled devices. Anyone with administrative access to these devices may be able to access those files.

Retention and deletion

Uploaded files remain in Google Drive until the owner deletes them. Local archives, tokens and logs remain until removed by the owner or the device's log retention settings. Stopping the backup does not delete existing copies. The owner can revoke My rclone access in the Google Account connections settings, stop the scheduled jobs, remove the local rclone remote and delete unwanted files in Google Drive and local storage. Revocation does not automatically delete previously uploaded files.

Google API data policy

My rclone's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
