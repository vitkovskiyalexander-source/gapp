My rclone

A personal file transfer and photo backup setup operated by its owner using rclone. This is an independently configured OAuth application, not an official Google or rclone service.

What it does

My rclone copies the owner's iCloud photo libraries into separate backup folders in the owner's Google Drive. Scheduled transfers run on the owner's device. Existing matching files are skipped. The configured backup uses copy operations and does not delete destination files.

Why Google Drive access is requested

The setup uses the Google Drive API to list files and metadata, compare destination copies, create folders and upload backup files. Its configured OAuth scope is full Google Drive access, which also permits reading, modifying and deleting files. The current backup jobs use listing and upload operations. Access is authorized by the Google account owner; there is no public registration or hosted file processing service.

Data use

Photo contents pass through the owner's device to Google Drive. OAuth tokens stay in the owner's local rclone configuration. Google user data is not sold or used for advertising or AI training. This application does not generate images or provide AI image generation functionality.

Read the privacy policy for data handling, retention and revocation details.

Operator

This is a private setup maintained by its account owner. There is no public support service.
