Политика конфиденциальности Personal File Transfer Приложение предназначено для личного переноса файлов с помощью rclone. Доступ и использование. Приложение использует Google Drive API для чтения файлов и метаданных, проверки копий и загрузки файлов. Выданное разрешение также позволяет изменять и удалять файлы согласно настройкам владельца. Передача и защита. Данные передаются через HTTPS и используются только для операций с файлами. Они не продаются, не используются для рекламы или обучения ИИ. Токены доступа хранятся локально с ограниченными правами доступа. Журналы могут содержать названия и пути файлов. Хранение и удаление. Файлы сохраняются в Google Drive до удаления владельцем. Локальные токены и журналы сохраняются до их удаления владельцем. Доступ можно отозвать в настройках Google-аккаунта; ранее загруженные файлы при этом не удаляются.
